# 需求说明

## 一、项目背景

原有小工具（`final_encoding_fixed_rename_asc/desc.bat`）只能对本文件夹内文件
**按大小排序 + 千字文相邻两字编码** 重命名，功能有限，无法满足实际业务需求。

本项目 `批量文档重命名助手` 是其升级替代品。

## 二、核心诉求

1. **批量重命名**：一次处理数百个文件，服务于批量发送律师函、账单等业务。
2. **识别文档身份**：识别文件名中的序号、姓名占位（如 `《①致xxx律师函》`）。
3. **导入名单对号入座**：导入客户名单（Excel/txt），把姓名准确匹配到对应文件。
4. **图形界面**：提供交互式 UI 面板，方便导入名单、预览与执行。
5. **交付形态**：Windows exe，双击即用。

## 三、功能清单

### 已实现（v1.0.0）

| 模块 | 功能 |
| --- | --- |
| 名单导入 | Excel(.xlsx/.xls)、CSV、txt；自动识别姓名列、自动跳表头 |
| 文件扫描 | 按类型筛选（Word/Excel/PDF/图片/全部）、递归子目录、排除名单文件与临时文件 |
| 文件名解析 | 提取序号（①②③、1./01、第1号、(1)、【1】、中文数字）、姓名候选、占位符识别 |
| 匹配引擎 | 按姓名模糊匹配（含一对一贪心分配）、按顺序一一对应、失败按顺序补齐 |
| 模板引擎 | `{序号} {姓名} {原名} {主体} {扩展名}`，序号起始/位数可调，可选原名内姓名替换 |
| 预览与校验 | 完整重命名计划、冲突高亮（重名/已存在/非法/缺姓名/未变） |
| 执行 | 两段式安全改名、进度反馈、错误明细 |
| 撤销 | 每次执行留档，一键整体回滚 |
| 导出 | 生成"原名→新名"Excel 对照表 |
| 日志 | 按日期写日志文件，记录每一步操作 |

### 后续可选增强（未实现）

- Word/Excel **内容**级识别（读取文档正文/单元格中的姓名）。
- PDF 文本层识别。
- 姓名拼音占位符、多字段模板（公司名、金额、日期）。
- 名单与文件的模糊匹配阈值可视化调节。
- 操作历史面板（浏览并回滚任意一次历史操作）。

## 四、关键设计决策

1. **命名完全由"名单 + 模板"驱动**，与旧工具的千字文编码无关。
2. **默认序号跟随名单顺序**：`按姓名识别`模式下，`0001` 对应名单第 1 人，符合发函编号习惯。
3. **安全优先**：绝不直接改文件，先生成计划供预览；执行留档可撤销。
4. **技术栈**：Python 3.9 + Tkinter(ttk) + openpyxl，PyInstaller 打包为单文件 exe。
