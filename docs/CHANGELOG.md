# 更新日志

## v1.1.1 (2026-10-13)

### 新增
- **悬停说明（Tooltip）**：鼠标停在任一参数/控件上约 0.4 秒，即浮现暗色说明气泡。
  涵盖目标文件夹、名单导入（说明支持 Excel/CSV/txt 及自动识别姓名列）、姓名来源三模式、
  排序、顺序补齐、文件类型、模板与占位符、序号设置、四个操作按钮、预览表格等。
- **程序图标**：改用椎拳崇（Kensou）头像，exe 文件图标、启动页与主窗口/任务栏图标统一。

## v1.1.0 (2026-10-13)

### 新增
- **启动权利声明页**：每次启动先显示约 1.9 秒的声明页，载明作者与"免费软件"声明。
- **顶部版权横幅**：主界面顶部常驻程序名、版本号与版权信息
  （免费软件 freeware · © 2026 田野（麦田律 / mikelawyer）· 北京执业律师）。
- 全局字体统一调大（微软雅黑 11 号），并加大控件内边距，
  避免文字被输入框/下拉框边框裁切。

### 优化
- **界面改为仿 Trae 暗色主题**：深灰底（#1e1e1e / #252526），
  输入框、表格、状态栏、下拉列表全部适配暗色；表格"可执行/未变/异常"用亮色区分。
- 移除不再使用的 `ttkthemes` 依赖（改为内置 clam 主题 + 自定义配色），打包体积进一步精简。

## v1.0.4 (2026-10-13)

### 修复
- **修复"错位"问题**：在「从文件名识别」模式下，若文件名里没有姓名，
  程序会静默地按名单顺序补齐，导致姓名与文档内容不对应、却仍显示为"可执行"。
  现在只要发生顺序补齐，就会弹出醒目提醒并在状态栏标注数量。
- 「从文档内容识别」模式下，**文件名中的字样不再参与匹配**，
  避免文件名里的旧名字"抢走"别人的姓名；仅在正文识别不到姓名时才退回用文件名。

### 变更
- 默认「姓名来源」改为 **「从文档内容识别」**（更符合"按文档内容对号入座"的实际用法）。

## v1.0.3 (2026-10-13)

### 变更
- 默认序号改为**阿拉伯数字样式、2 位补零**，1~99 个文件产出 `01`、`02`…`99`，
  整齐统一，避免圈号（①②③）超过 50 个后回退为数字导致序号样式不一致。
- 预设模板名由 `《①致姓名缴费通知书》` 调整为 `《01致姓名缴费通知书》`（模板内容不变）。
- 圈号样式仍保留可选（适合 50 个以内的文件）。

## v1.0.2 (2026-10-13)

### 新增
- `src/core/content_reader.py`：从文档**正文内容**中提取称谓姓名（如
  "尊敬的张三，您作为原告的案件…" → 张三）。支持 .docx / .xlsx，
  用标准库 zipfile + xml 解析 OOXML，不引入额外依赖。
- 匹配方式新增「从文档内容识别」：导入名单后，按文档正文里的称谓与名单
  对号入座，适用于文件名混乱、只能靠内容判断收件人的场景。
- 序号样式新增「圈号（①②③）」「中文（一二三）」，可直接产出
  `《①致张三的缴费通知书》` 这类名称。

### 说明
- 圈号序号 Unicode 仅提供 ①-⑳、㉑-㉟、㊱-㊿ 共 50 个标准字形；
  第 51 个起自动回退为阿拉伯数字（如需 99 个连续序号，建议改用阿拉伯数字样式）。

## v1.0.1 (2026-10-13)

### 新增
- `src/core/serializer.py`：核心数据结构（文件/解析结果/名单/匹配/计划）的 JSON 序列化支持。
- `src/core/api.py`：纯函数式 JSON 接口层（`pipeline` / `execute_plan` / `undo_last`），
  作为核心逻辑与界面/平台之间的唯一契约，为鸿蒙（ArkTS）移植预留通道。

### 优化
- **绿色运行更健壮**：若 exe 所在目录不可写（如只读盘、Program Files），
  日志/对照表目录自动回退到用户目录，保证"双击即用"在任何位置都能工作。
- **打包体积优化**：排除 numpy/scipy/PIL/matplotlib/pandas 等无关模块，exe 明显减小。
- 新增 `docs/鸿蒙移植准备.md`，说明移植路线与编码纪律。

## v1.0.0 (2026-10-13)

### 新增
- 图形界面（Tkinter/ttk），含名单导入面板、预览表格、进度反馈。
- 名单导入：支持 Excel(.xlsx/.xls)、CSV、纯文本(.txt)，自动识别姓名列与表头。
- 文件名解析：识别序号（①②③、1./01、第1号、(1)、【1】、中文数字）、
  姓名候选、姓名占位符（xxx/XXX/某某），兼容 `《①致张三律师函》` 这类被书名号包裹的名称。
- 匹配引擎：
  - 按文件名中的姓名智能匹配（一对一贪心 + 相似度阈值）；
  - 按文件夹顺序一一对应；
  - 姓名匹配不上时按名单顺序补齐（可选）。
- 模板引擎：`{序号} {姓名} {原名} {主体} {扩展名}`，序号起始/位数可调，
  可选"在原文件名中替换识别到的姓名"。
- 重命名计划与冲突检测：目标重名、已存在、非法字符、Windows 保留名、缺少姓名、名称未变。
- 两段式安全执行（原名→临时名→目标名），执行留档、一键撤销。
- 导出 Excel 对照表。
- 日志系统：按日期写文件，记录每一步操作。

### 说明
- 本工具与旧 `rename` 工具的"千字文编码"命名方式无关；命名为"名单 + 模板"驱动。
