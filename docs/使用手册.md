# 使用手册

## 0. 启动

双击 `批量文档重命名助手.exe`。

> 首次启动若被 Windows 拦截，点"更多信息 → 仍要运行"即可。

## 1. 选择目标文件夹

点「浏览…」，选择存放待处理文档的文件夹。

- 勾选「包含子文件夹」可一并处理子目录。
- 在「文件类型」里勾选要处理的类型，或勾选「全部类型」。

## 2. 导入名单

点「导入名单…」，选择您的客户名单文件：

- **Excel (.xlsx / .xls)**：工具会自动跳表头、自动挑选"姓名"列。
- **纯文本 (.txt)**：每行一个姓名即可，行首的 `1.`、`①`、`第1号` 会被自动忽略。

导入后右上角显示"已加载名单：N 条"。点「查看名单」可核对内容。

> 名单文件若正好放在目标文件夹里，工具会自动把它排除，不会误改名。

## 3. 设置匹配方式

- **按文件名中的姓名识别**（推荐）：从文件名里解析姓名，与名单匹配。
  例：`《②致张三律师函》.docx` → 识别出"张三"，匹配名单中的张三。
- **按文件夹顺序对应名单**：文件名里没有姓名时使用，按排序后的文件顺序与名单顺序一一对应。

勾选「姓名匹配不上时按顺序补齐」可在姓名对不上时，用名单里剩余的人按顺序补位。

## 4. 填写命名模板

在「模板」框里填写，例如：

| 想要的命名 | 模板 |
| --- | --- |
| `0001_张三_律师函.docx` | `{序号}_{姓名}_律师函` |
| `0001张三律师函.docx` | `{序号}{姓名}律师函` |
| `张三_账单.xlsx` | `{姓名}_账单` |
| 在原名基础上加姓名 | `{原名}_{姓名}` |

也可从右侧「预设」下拉里快速选择。

- 「序号起始」：默认 1，即从 0001 开始。
- 「序号位数」：默认 4，即 0001、0002……设为 3 则 001。
- 「在原文件名中替换识别到的姓名」：勾选后，`{原名}` 里原有的姓名会被替换成匹配到的姓名。

## 5. 刷新预览

点「刷新预览」，表格显示：

| 列 | 含义 |
| --- | --- |
| 序号 | 新文件编号 |
| 原文件名 | 当前名称 |
| 识别序号 / 识别姓名 | 从原名中解析出的信息 |
| 匹配姓名 | 与名单匹配到的姓名 |
| 新文件名 | 将要改成什么 |
| 状态 | 可执行 / 名称未变 / 目标重名 / 目标已存在 / 非法名称 / 缺少姓名 |
| 备注 | 补充说明 |

**颜色**：绿色=可执行，橙色=名称未变（跳过），红色=有问题（会被跳过）。

> 执行前请务必核对红色行，通常是"名单里没有这个姓名"或"两人重名"。

## 6. 执行

点「执行重命名」，确认后开始。

- 执行完会提示成功/失败数量。
- 失败明细会显示前 5 条。

## 7. 撤销

点「撤销上次」，可把最近一次重命名整体还原。

## 8. 导出对照表

点「导出对照表」，在 `exports/` 目录生成 Excel，含原名→新名对照，便于发函前核对。

## 9. 日志

点「打开日志」查看 `logs/` 目录：

- `app_YYYYMMDD.log`：操作日志。
- `undo_YYYYMMDD_HHMMSS.json`：撤销记录。

## 常见问题

**Q：为什么有些文件状态是红色的"缺少姓名"？**
A：模板中用了 `{姓名}`，但该文件既没匹配到姓名、名单也已用完。检查名单是否漏人，或改用「按文件夹顺序对应名单」。

**Q：可以只重命名一部分文件吗？**
A：可以。先预览，把不希望处理的文件暂时移出文件夹，或在模板/匹配上调整后重新预览。

**Q：改错了怎么办？**
A：立即点「撤销上次」。
