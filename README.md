# 批量文档重命名助手 (BatchDocRenamer)

一款专为「批量发送律师函 / 账单」场景设计的 Windows 桌面工具：
**导入客户名单，自动把文件夹里数百个 Word / Excel 文档按模板批量重命名。**

它是旧 `rename` 小工具（按文件大小 + 千字文编码重命名）的完全升级版。

---

## 一、它能做什么

| 能力 | 说明 |
| --- | --- |
| 批量重命名 | 一次处理数百个文件，支持 Word / Excel（可扩展 PDF、图片等） |
| 导入名单 | 支持 Excel(.xlsx/.xls)、CSV、纯文本(.txt)，自动识别"姓名列" |
| 智能匹配 | 从 `《①致xxx律师函》` 这类文件名里解析序号与姓名，和名单"对号入座" |
| 两种匹配模式 | ① 按文件名中的姓名识别；② 按文件夹顺序对应名单顺序 |
| 自定义模板 | `{序号} {姓名} {原名} {主体} {扩展名}` 自由组合 |
| 预览确认 | 先看完整重命名结果（含冲突高亮），确认无误再执行 |
| 一键撤销 | 每次执行自动留档，可整体回滚 |
| 导出对照表 | 生成"原名 → 新名"Excel 对照表，发函前核对 |
| 全程日志 | 每次操作写入带时间戳的日志，可追溯 |

---

## 二、快速开始

### 1. 直接使用（推荐）
双击 `dist/批量文档重命名助手.exe` 即可，无需安装 Python。

### 2. 源码运行
```bash
pip install -r requirements.txt
python app.py
```

### 3. 自行打包 exe
```bash
python build_exe.py
# 产物在 dist/批量文档重命名助手.exe
```

---

## 三、使用流程

1. **选择目标文件夹**：存放待重命名文档的文件夹。
2. **导入名单**：选择 Excel / txt 名单，工具自动识别姓名列。
3. **设置匹配方式**：一般选"按文件名中的姓名识别"；若文件名里没有姓名，改选"按文件夹顺序对应名单"。
4. **填写命名模板**：如 `{序号}_{姓名}_律师函`。
5. **点击「刷新预览」**：表格会显示每个文件的"原文件名 → 新文件名"及状态。
6. **点击「执行重命名」**：确认后批量改名。
7. 如结果不对，点 **「撤销上次」** 回滚。

### 模板占位符

| 占位符 | 含义 |
| --- | --- |
| `{序号}` | 序号（按设置补零，如 0001） |
| `{姓名}` | 匹配到的名单姓名 |
| `{原名}` | 原文件名（不含扩展名） |
| `{主体}` | 原文件名去掉序号后的主体 |
| `{扩展名}` | 原扩展名（含点，如 .docx） |

## 五、安全设计

- **绝不直接改文件**：所有操作先生成"计划"，预览确认后才执行。
- **两段式改名**：原名 → 临时名 → 目标名，避免互相覆盖。
- **冲突拦截**：目标重名、已存在、非法字符、Windows 保留名自动标红跳过。
- **自动留档**：每次执行写入 `logs/undo_*.json`，支持一键撤销。

---

## 六、绿色运行说明

- 交付物为**单个 exe**，`--onefile` 打包，**无需安装、无需携带任何素材/依赖**，双击即用。
- 所有资源（界面主题等）均已打进 exe。
- 运行时会在 exe 同目录生成 `logs/`、`exports/`；若该目录不可写（只读盘、Program Files 等），
  会**自动回退**到用户目录，保证在任何位置都能正常工作。

## 七、后续平台适配（鸿蒙）

界面（Tkinter）与核心逻辑（`src/core/`）已**彻底解耦**，且核心数据结构全部支持 JSON。
`src/core/api.py` 提供 `pipeline / execute_plan / undo_last` 三个纯函数 JSON 接口，
作为跨平台/跨语言的对接契约，便于后期适配鸿蒙（ArkTS/ArkUI）。

详细路线与编码纪律见 [docs/鸿蒙移植准备.md](docs/鸿蒙移植准备.md)。
